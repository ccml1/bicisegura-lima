# BiciSegura Lima

Mapa colaborativo, estilo Waze, para ciclistas de Lima: los propios usuarios reportan y validan en tiempo real robos, accidentes, tramos en mal estado, vehículos en la ciclovía, calles enrejadas y ciclovías interrumpidas. Un evento queda **verificado con 3 confirmaciones de personas distintas** y las estadísticas por calle y distrito se calculan solo con eventos verificados.

- Jira: https://ccml01.atlassian.net/jira/software/projects/EXAMPFC/boards/74
- Ramas: `main` (producción) ← `test` (pruebas) ← `feature/EXAMPFC-<n>-<descripcion>` (una por historia de usuario)
